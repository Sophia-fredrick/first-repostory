Personal Daily Expense Tracker

A simple expense-tracking app that helps individuals record and review their daily spending. Users can add expenses with an amount, date, category, and optional note, then view their spending history to better understand where their money goes.

## Features

- Add, edit, and delete expenses
- Categorize expenses, such as food, transport, bills, and entertainment
- View expenses by day or month
- See total spending for a selected period
- Review spending history

## Purpose

This project is designed to make it easier to track everyday purchases, manage a personal budget, and build better spending habits.
